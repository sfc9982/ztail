# Shells, colors, and localization / Shell、颜色与本地化

## Completion / 自动补全

`ztail --completions SHELL` prints a static completion script to stdout and exits.
Supported names: `bash`, `zsh`, `fish`, `elvish`, `powershell`. It needs no file
operand and never adds ANSI color. Generate scripts with `--language=en` for
portable English descriptions or `--language=zh-CN` for Chinese descriptions.
Completion generation does not read log files or enable follow mode.

```sh
# Bash: current session; add the source line to ~/.bashrc for persistence.
mkdir -p ~/.local/share/bash-completion/completions
ztail --completions bash > ~/.local/share/bash-completion/completions/ztail
source ~/.local/share/bash-completion/completions/ztail

# Zsh: add this directory to fpath BEFORE compinit in ~/.zshrc.
mkdir -p ~/.zfunc
ztail --completions zsh > ~/.zfunc/_ztail
# fpath=(~/.zfunc $fpath)
# autoload -Uz compinit && compinit

# Fish (automatically loaded from this directory).
mkdir -p ~/.config/fish/completions
ztail --completions fish > ~/.config/fish/completions/ztail.fish

# Elvish: save as ~/.config/elvish/lib/ztail.elv, then `use ztail` in rc.elv.
mkdir -p ~/.config/elvish/lib
ztail --completions elvish > ~/.config/elvish/lib/ztail.elv
```

PowerShell (`pwsh` on Linux/WSL), current session:

```powershell
ztail --completions powershell | Out-String | Invoke-Expression
# Persist by saving ztail.ps1 under your config directory and dot-sourcing it
# from $PROFILE. Only load scripts generated by a trusted ztail binary.
```

These are static option/path completions, not dynamic log-content completions.
Regenerate them after upgrading. A file named `completions` is still a file operand;
use `--` for names beginning with `-`.

## Color / 颜色

- `--color auto` (default): decide stdout and stderr independently by terminal.
  Redirected streams contain no added ANSI codes unless forced via the environment.
- `--color always|never` explicitly overrides all environment settings.
- In auto mode: nonempty `NO_COLOR` disables color; otherwise nonzero, nonempty
  `CLICOLOR_FORCE` forces it (including pipes); otherwise `CLICOLOR=0` or
  `TERM=dumb` disables it. Empty variables have no effect.
- Color applies only to help, file-name headers, and diagnostics. Log bytes are
  **never changed**, including any control sequences already present in the log.
  `-q` suppresses headers; `--color never` does not sanitize malicious log data.

颜色只用于界面，不会为日志添加或移除颜色码。自动模式分别判断标准输出与标准
错误；管道默认无新增颜色。处理不可信日志时仍需使用安全的查看环境。

## Language / 语言

`--language en` or `--language zh-CN` selects the UI language. Otherwise the first
nonempty variable in `LC_ALL`, `LC_MESSAGES`, `LANG` wins. Simplified Chinese
locales (`zh_CN`, `zh_SG`, `zh-Hans`, with optional encoding/modifier) select
Chinese. All other locales, including `C`, fall back to English. The `LANGUAGE`
variable is deliberately not interpreted. Language never changes filenames,
option names, completion shell names, file decoding, or output log bytes.

目前提供英文和简体中文。帮助、应用层错误及跟随状态提示已本地化；clap 参数
解析器的详细错误、操作系统错误及底层解码器错误保留原始英文（中文界面会提供
中文错误类别），避免丢失诊断细节。操作系统错误语言也可能由系统自身决定。

Examples:

```sh
ztail --language zh-CN --help
LC_MESSAGES=zh_CN.UTF-8 ztail -F application.log.gz
NO_COLOR=1 ztail -v application.log.gz
ztail --color never -n 100 application.log.gz > last.log
```
